**Type:** Learning checkpoint

## Overview

This checkpoint documents my Python practice with core data structures and a few standard-library tools. It is a **learning checkpoint, not an original project**. The goal was to practice the concepts directly, keep clear notes, and build a foundation I can explain in my own words.

## Topics Covered

- Lists
- Tuples
- Dictionaries and dictionary methods
- Sets and set methods
- `split()` and `join()`
- Modules
- `random`
- `datetime`
- Custom modules
- `pip` / `pip3`
- `time`

## What I Practiced

### Lists
- Storing multiple values in one variable
- Ordered, mutable collections
- Indexing beginning at `0`
- Looping through a list
- Using common list methods such as `append()`, `insert()`, `remove()`, `index()`, and `count()`

### Tuples
- Storing multiple values in an immutable collection
- Accessing tuple values by index
- Looping through tuple values
- Understanding that a tuple must be converted to a list before changing its contents, then converted back if needed

### Dictionaries
- Using `clear()`, `copy()`, `keys()`, `values()`, `items()`, and `update()`
- Looping through dictionary values with `.values()`
- Looping through key-value pairs with `.items()`

### Sets
- Working with unique, unordered values
- Understanding that sets do not use indexing
- Looping through set values
- Using `add()`, `update()`, `clear()`, `pop()`, `remove()`, and `discard()`
- Comparing sets with `intersection()`
- Combining sets with `union()`

### Strings
- Using `.split()` to break one string into multiple pieces
- Using `.join()` to combine multiple strings into one string

### Modules and Packages
- Importing built-in modules
- Creating and importing a custom module
- Using the `random` module for random values and selections
- Using the `datetime` module for dates, times, and format codes
- Understanding the purpose of `pip` and `pip3`
- Using the `time` module for timestamps, timing, and pauses

## Key Takeaways

- Lists are ordered and mutable.
- Tuples are ordered but immutable.
- Dictionaries work with key-value pairs.
- Sets store unique values and do not use indexing.
- `.split()` takes a string apart; `.join()` puts strings together.
- Modules make Python code reusable and easier to organize.
- Built-in modules such as `random`, `datetime`, and `time` provide functionality without rewriting it from scratch.
- `pip` is used to install external Python packages.
