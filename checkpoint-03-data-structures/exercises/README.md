# Checkpoint 3 Exercises

This checkpoint consisted of small practice exercises completed while learning the material rather than a separate original project.

Practice included:

- Creating and looping through lists
- Using list methods
- Creating and looping through tuples
- Working with tuple immutability
- Using dictionary methods
- Looping through dictionary values and key-value pairs
- Creating and looping through sets
- Using common set methods
- Comparing sets with `intersection()` and `union()`
- Practicing `.split()` and `.join()`
- Importing and using built-in modules
- Creating and importing a custom module
- Practicing `random`, `datetime`, `pip` / `pip3`, and `time`

No standalone project was assigned for this checkpoint, so this folder documents the exercises only.
