# Evidence

The screenshots in this folder are selected examples from the OS module practice completed during this Section 5 checkpoint.

The screenshots were sanitized for the public repository by redacting the local Windows username and personal filesystem paths.

Included evidence:

- `01-getcwd.png` — checking the current working directory
- `02-listdir.png` — listing directory contents
- `03-listdir-loop.png` — looping through directory contents
- `04-chdir-verify.png` — changing and verifying the working directory
- `05-mkdir.png` — creating a directory and verifying it with `ls`
- `06-rmdir.png` — removing the empty directory and verifying it was removed
